# THE VIEW – Yacht Restaurant

> Landing Page du thuyền nhà hàng ven sông Hàn, Đà Nẵng (Thương hiệu con thuộc hệ sinh thái ẩm thực TGIF Group).

## Giới thiệu
Trang giới thiệu chính thức của **THE VIEW – Yacht Restaurant** (Tầng 1, Du thuyền Happy Yacht, P. An Hải Tây, Sơn Trà, Đà Nẵng).

## Công nghệ sử dụng
- **Next.js 16** (App Router)
- **React 19**
- **Tailwind CSS v4**
- **Google Fonts**: Playfair Display & Be Vietnam Pro
- **Lucide Icons & Phosphor Icons**

## Cài đặt & Chạy cục bộ

```bash
# Cài đặt thư viện
npm install

# Chạy môi trường phát triển
npm run dev

# Build sản phẩm
npm run build
```

Mặc định máy chủ sẽ chạy tại `http://localhost:3001` (hoặc `http://localhost:3000`).
